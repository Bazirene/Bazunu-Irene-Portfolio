### 7. 🔐 Password Strength & Breach Checker with Watchdog Log Anonymization

**Credential Security & Privacy-Preserving Breach Detection**

A Python-based credential security auditing tool developed on Kali Linux to assess password strength, check exposure against known data breaches, and monitor credential logs in real time.
Built with Streamlit, SQLite, Python Watchdog, `zxcvbn`, and the Have I Been Pwned (HIBP) API, the application combines password analysis, breach checking, and automated log sanitization.

The project demonstrates practical security engineering work including:

- Privacy-preserving breach verification using the HIBP k-anonymity model
- Password complexity scoring and estimated crack-time analysis with `zxcvbn`
- Real-time filesystem monitoring of `passwords.log`
- Automated replacement of plaintext credential entries with SHA-1 hashes
- Structured security event logging in SQLite
- Interactive Streamlit dashboard for password analysis and secure passphrase generation
- Historical audit viewing and verification testing for breached and high-entropy passwords

**Tools:** Python, Streamlit, SQLite, Watchdog, HIBP API, `zxcvbn`, and SHA-1 hashing.

🔗 **Repository:** [View Password Strength & Breach Checker](https://github.com/Bazirene/ProStackHub_Password_Strength-Breach_Checker.git)


### 8. 🛡️ Host-Based Intrusion Detection (HIDS) + SOC AI Log Chatbox

**Threat Detection, Security Operations & AI-Assisted Incident Response**

A Python-based Host-Based Intrusion Detection System developed on Kali Linux to monitor authentication logs, detect suspicious activity, and support security investigations through an AI-assisted security operations dashboard.

Using Python Watchdog, regular-expression-based detection, SQLite, Streamlit, and the Groq API, the application identifies suspicious authentication events and helps analysts interpret security alerts.

The project demonstrates practical security engineering work including:

- Continuous monitoring of Linux authentication logs
- Detection of SSH brute-force attempts and failed authentication
- Identification of suspicious sudo and privilege-escalation activity
- Structured alert storage in SQLite with timestamps, severity levels, and source IP addresses
- Streamlit dashboard for security metrics and alert investigation
- AI-assisted incident triage and threat summarization using recent security logs
- Controlled attack simulation using THC-Hydra to validate detection behavior
- Defensive remediation recommendations and secure API-key management

**Tools:** Python, Watchdog, SQLite, Streamlit, Groq API, Linux authentication logs, THC-Hydra, and Bash.

🔗 **Repository:** [View HIDS + SOC AI Log Chatbox](https://github.com/Bazirene/ProStackHub_Host-Based-Intrusion-Detection-System-HBID-AI-Log-Chatbox.git)

### 9. 🔎 Network Vulnerability Scanner

**Network Security Assessment & Automated CVE Detection**

A Python-based full-stack network vulnerability scanner developed on Kali Linux to identify open ports, detect running services and software versions, and investigate known security vulnerabilities.

Built using Flask, Nmap, the NIST National Vulnerability Database (NVD) REST API, and ReportLab, the application provides a web dashboard for viewing scan results and generating downloadable PDF vulnerability assessment reports.

The project demonstrates practical security engineering work including:

- Network reconnaissance and open-port discovery using Nmap
- Service and software version detection
- NVD API integration for vulnerability research
- CVE identification and CVSS severity assessment
- Automated vulnerability lookup based on detected software information
- Flask-based dashboard for entering authorized targets and viewing findings
- PDF vulnerability report generation using ReportLab
- Modular Python development across scanning, vulnerability lookup, reporting, and web interface components

**Tools:** Python, Flask, Nmap, `python-nmap`, NVD REST API, Requests, and ReportLab.

🔗 **Repository:** [View Network Vulnerability Scanner](https://github.com/Bazirene/ProStackHub_Network-Vulnerability-Scanner.git)
